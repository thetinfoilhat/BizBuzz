# BizBuzz

Official repository for the BizBuzz NFP website (bizbuzz.it).

BizBuzz is a free entrepreneurship program for students in grades 3–8. The site is built with Next.js and lives in the `bizbuzz/` folder.

## Running it

```
cd bizbuzz
npm install
npm run dev
```

Then open http://localhost:3000.
